# Functional Variant Impact Analysis

A pipeline for interpreting biological consequences of genomic variants from VEP-annotated VCF files.

## Analyses
- **GO Enrichment** — Overrepresented biological processes
- **Variant Prioritization** — Impact scoring for clinical follow-up
- **Protein Domain Analysis** — Missense variant mapping
- **Effector Gene Screening** — Pathogenicity factor mutations
